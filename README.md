This project explores health care data to predict fraudulent claims and evaluate which features are most predictive of fraudulent claims. Sections include exploratory data analysis, visualization EDA, and classification machine learning models. The data set possesses key categorical and numeric features including days between service and claim, claim status, claim amount, and approved amount. Random Forest and Gradient Boosting classification methods are utilized with the final model being selected based on cross validation scoring. Classification metrics including confusion matrix and classification report are used to evaulate model performance and interpret findings.
